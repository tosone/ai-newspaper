# AI newspaper

A newspaper-styled archive of AI daily, weekly and monthly briefings collected from
[AIHOT](https://aihot.news). A single page lists every generated issue behind daily /
weekly / monthly tabs and renders the selected one as a broadsheet — masthead, front-page
lead, multi-column body, ranked board and all. All content lives in plain JSON files under
`data/` (daily/年/月, weekly, monthly), and any single issue can be shared with a `?doc=<id>` link.

Live: https://ainews.tosone.cn/
